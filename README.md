Third law

Game Genre : Parkour/Rage Game

Controls : 
 
 W A S D     : Movement 
 SPACEBAR    : Jump
 SHIFT       : Sprint   
 LEFT CLICK  : Object Throw
 RIGHT CLICK : Repulse in Opposite Direction of Throw
 E           : Grab Object/Interact
 F           : Gravity Inversion ( certain areas only, for game design purposes )
 Q           : Use dark matter to Imagine Platforms - Press Again to Create platform - Press Again to Dematerialize Platform 
               ( Cycle based )

Story/Background :
  
 Earth, that we know of, died a cold death a decade ago. A Spaceship was launched with the pinaccle of space technologies just before the end with the Ultimate Hope of Reverting the Damage done to our Earth through Manipulating the Space Time fabric with the help of the Reactor Core that the ship was equipped with. But the Cadet ( you/the player ) was hit with another tragedy as the reacter core became unstable dude to gravitational fields of Dark Matter. So the Only hope of human endaveour was tied to the esacpe of the cadet. By using the Gravity Gloves ( The ultimate Alien Device ) and Manipulating Matter and even Dark Matter, you as the last hope of humanity have to get out of the ship while beating all the odds.
